## 三、CSV 批量导入（✅ 已实现）

### 后端 `app/api/users.py` 追加

```python
@router.post("/import")
async def import_users(file: FastUploadFile = File(...),
                       db: Session = Depends(get_db),
                       _: User = Depends(require_admin)):
    """★ CSV 批量导入用户

    CSV 格式（第一行是表头）：
        工号,姓名,组别,密码,角色
        2024001,张三,视觉,123456,member
        2024002,李四,机械,123456,member

    角色可选：member / admin（默认 member）
    """
    import csv, io
    content = await file.read()
    text = content.decode("utf-8-sig")          # 兼容 Excel 的 BOM
    reader = csv.DictReader(io.StringIO(text))

    created, skipped, errors = 0, 0, []
    for i, row in enumerate(reader, start=2):
        emp_no = (row.get("工号") or "").strip()
        name = (row.get("姓名") or "").strip()
        if not emp_no or not name:
            errors.append(f"第 {i} 行：工号或姓名为空")
            continue
        if db.query(User).filter(User.emp_no == emp_no).first():
            skipped += 1
            continue
        role = (row.get("角色") or "member").strip()
        if role not in (ROLE_ADMIN, ROLE_MEMBER):
            role = ROLE_MEMBER
        u = User(
            emp_no=emp_no,
            name=name,
            group_name=(row.get("组别") or "").strip(),
            password_hash=hash_password((row.get("密码") or "123456").strip()),
            role=role,
        )
        db.add(u)
        created += 1

    db.commit()
    return ok({"created": created, "skipped": skipped, "errors": errors},
              f"导入完成：新增 {created}，跳过 {skipped}，错误 {len(errors)}")
```

**注意：`app/api/users.py` 顶部要加 import：**


## 四、建议做的三件事

### P1-1 · 任务通知（微信群，未做）

**最简单方案：企业微信机器人 Webhook**

```python
# app/core/notify.py
import httpx
from app.core.config import settings

async def notify_wecom(content: str):
    """发到企业微信机器人（在群里创建机器人拿到 webhook）"""
    url = settings.WECOM_WEBHOOK
    if not url:
        return
    try:
        async with httpx.AsyncClient(timeout=5) as c:
            await c.post(url, json={"msgtype": "text",
                                    "text": {"content": content}})
    except Exception:
        pass    # ★ 通知失败不能影响主流程
```

**在 `create_task` 里调用：**

```python
await notify_wecom(f"📋 新任务：{body.title}\n"
                   f"接收人：{assignee.name}（{assignee.group_name}）\n"
                   f"截止：{body.deadline}\n"
                   f"请登录系统查看详情")
```

**★★ 通知失败不能让任务发布失败 —— 必须 try/except 吞掉。**

## 五、30 人用的日常节奏（建议）

### 每周一 09:00

```
队长 → 发本周任务（5~10 个）
     → 每个组员至少 1 个
```

### 每天

```
队员 → 晚上看一眼有没有新任务
     → 干完就提交
```

### 每周五 18:00

```
各组组长 → 审核本组提交
        → 通过 or 驳回（写理由）
队长 → 看整体提交率
     → 低于 70% 要开会
```

### 每月末

```
队长 → 备份数据库
     → 导出「任务完成统计」做复盘
```
