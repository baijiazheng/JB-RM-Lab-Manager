# 02 · 管理员手册

> 适用：管理员（队长、副队、组长）
> 最后更新：2026-11-06

---

## 一、管理员能做什么

```
① 用户管理：新增/编辑/重置密码/删除
② 任务发布：给指定队员下发任务
③ 任务管理：查看全部、审核、驳回、改状态、删除
④ 提交记录：看所有人的提交、下载附件
```

---

## 二、用户管理

### 新增队员

```
侧边栏 → 用户管理 → 新增队员

填写：
  · 工号（学号，唯一，不能重复）★ 建成后不能改
  · 姓名
  · 组别（视觉/机械/电控/运营/管理）★ 可以自己输入新的
  · 密码（至少 6 位）
  · 角色（队员 / 管理员）
```

**★ 建议：**
```
· 每个组至少设 1 个管理员（组长），方便自己发任务
· 管理员能看所有人的任务，不要随便给
```

### 编辑用户

```
只能改：姓名 / 组别 / 角色
不能改：工号（因为工号是登录账号）
```

### 重置密码

```
用户管理 → 对应行 → 「重置密码」→ 输入新密码
```

**★ 队员忘记密码时，你帮他重置，然后口头告知。**

### 删除用户

```
⚠️ 删除后，他名下的任务还会保留（但接收人显示为空）
→ 建议：退役队员先改成「已退出」组别，不要直接删
```

---

## 三、任务发布

### 发布流程

```
侧边栏 → 任务管理 → 发布任务

填写：
  · 标题（一句话说清要干什么）★ 必填
  · 接收人（下拉选，可搜索）★ 必填
  · 截止时间（日期时间选择器）
  · 描述（详细说明）
  · 要求（验收标准）
```

**★★ 写任务的建议：**

```
❌ 差：「做视觉标定」
✅ 好：「用 A4 棋盘格标定 DaBai 相机
       1. 拍 15 张不同角度
       2. 跑 calib_live.py
       3. 报告 RMS / fx / cx / cy
       验收：RMS < 0.5」
```

**★ 任务要能"验收"，不能只是"做了"。**

---

## 四、任务审核

### 通过

```
任务管理 → 状态为「已提交」的行 → 「通过」
→ 状态变 done（已完成）
```

### 驳回

```
任务管理 → 「驳回」→ 输入理由（必填）
→ 状态变 rejected（已驳回）
→ 队员能看到理由，改完重新提交
```

**★ 驳回理由要具体：**
```
❌ 差：「不合格」
✅ 好：「RMS 1.9 太大了，检查是不是有一张图拍糊了，
       逐张看误差剔除 >2.5×RMS 的图」
```

### 手动改状态

```
任务管理 → 「改状态」→ 输入 pending/doing/submitted/rejected/done
```

**用途：**
```
· 队员忘了标记"进行中" → 你帮他改
· 任务实际上没开始 → 改回 pending
```

## 五、查看提交记录

```
侧边栏 → 提交记录

能看到：
  · 所有任务的提交
  · 谁提交的
  · 提交内容
  · 附件（点击下载）
  · 时间
```

**★ 这是"收作业"的主界面。**

## 六、日常运营建议（30 人队伍）

### 每周一

```
① 看「提交记录」，检查上周任务完成情况
② 给未完成的人发提醒（微信或当面）
③ 发布本周任务
```

### 每周五

```
① 审核所有「已提交」的任务
② 通过 or 驳回（驳回要写理由）
③ 看「我的工作台」的统计，评估进度
```

### 每月

```
① 备份数据库（见部署手册）
② 清理已离职队员
③ 复盘任务完成率
```

## 七、任务模板（建议）

### 视觉组

```
标题：标定 DaBai 相机
描述：用 A4 棋盘格（25mm）拍 15 张，跑 calib_live.py
要求：报告 RMS / fx / fy / cx / cy，RMS < 0.5 才算过
```

### 机械组

```
标题：云台支架刚性改进
描述：板厚从 2mm 改到 3mm，加 2 条加强筋
要求：出图 + 实物，手掰不变形
```

### 电控组

```
标题：C 板跑通 CAN 通信
描述：两块 C 板互发数据，1Mbps
要求：连续 10 分钟无丢包，附串口截图
```
