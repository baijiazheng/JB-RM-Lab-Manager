# 01 · 使用手册（所有队员看这个）

> 适用：30 人队伍的全部成员
> 最后更新：2026-11-06

---

## 一、怎么登录

```
1. 浏览器打开（内网地址，由管理员告知）
   例：http://192.168.1.100:5173

2. 输入【工号】+【密码】
   · 工号 = 你的学号（管理员分配）
   · 首次密码 = 管理员告知的初始密码

3. 登录成功 → 进入「我的工作台」
```

**⚠️ 连续输错 5 次会锁 5 分钟。**

## 二、队员能看到什么

### 我的工作台

```
┌─────────────────────────────────────┐
│ 未开始 3  │ 进行中 2 │ 待审核 1 │ 已完成 8 │
└─────────────────────────────────────┘

我的任务
┌────┬──────────────┬────────┬──────────┬──────┐
│ ID │ 标题          │ 状态   │ 截止时间  │ 操作 │
├────┼──────────────┼────────┼──────────┼──────┤
│ 12 │ 视觉标定报告   │ 进行中 │ 11-10    │ 查看 │
│ 11 │ 机械装配图     │ 已完成 │ 11-05    │ 查看 │
└────┴──────────────┴────────┴──────────┴──────┘
```

**四个统计卡的含义：**
| 卡 | 含义 | 你要做什么 |
|---|---|---|
| **未开始** | 管理员刚发，你还没动 | 看详情，开始干 |
| **进行中** | 你可以手动标记（目前由管理员改）| 继续干 |
| **待审核** | 你提交了，等管理员看 | 等 |
| **已完成** | 管理员通过了 | 收工 |

**★ 注意：「已驳回」不在这四个卡里，但状态会显示在列表里 —— 要重新提交。**

## 三、任务详情页

### 能看到什么

```
· 状态（未开始/进行中/已提交/已驳回/已完成）
· 截止时间
· 发布人 / 接收人
· 任务描述（要干什么）
· 要求（验收标准）
· 驳回理由（如果被驳回）
```

### 怎么提交

```
1. 点「查看」进详情页
2. 在「提交任务」区域：
   · 填写文字内容（干了什么、结果如何、遇到什么问题）
   · 点「选择附件」上传文件（图片/文档/压缩包，单个 ≤50MB）
3. 点「提交」
```

**★★ 提交后状态自动变成「已提交（待审核）」。**

### 附件上传注意

```
✅ 支持：图片（jpg/png）、文档（pdf/docx）、压缩包（zip/7z）
✅ 单个文件 ≤ 50MB
✅ 可以一次选多个
❌ 不支持：可执行文件、超大文件
```

### 提交历史

```
页面底部能看到你在这个任务上的【所有提交】
→ 被驳回后重新提交，历史会保留
```

## 四、任务状态说明（重要）

```
pending（未开始）
   ↓
doing（进行中）
   ↓ 你提交
submitted（已提交，待审核）
   ├── 管理员通过 → done（已完成）
   └── 管理员驳回 → rejected（已驳回，有理由）
                      ↓ 你看理由，改完重新提交 → submitted
```

**★ 被驳回不是惩罚，是"再改改" —— 看驳回理由，改完重新提交。**

## 五、常见问题

| 问题 | 解决 |
|---|---|
| **忘记密码** | 找管理员重置（不能自己改）|
| **登录提示"尝试次数过多"** | 等 5 分钟再试 |
| **看不到任务** | 任务可能还没分配给你，问管理员 |
| **上传附件失败** | 检查文件是否 >50MB |
| **提交后想改** | 等管理员驳回，或让管理员帮你改状态 |
| **页面打不开** | 确认连的是实验室 WiFi，后端是否在运行 |

## 六、用手机能用吗

**能用，但体验一般。**

```
本项目按【电脑浏览器】设计，没做移动端适配
手机上能打开，但表格会挤
→ 提交任务、看详情没问题
→ 管理功能建议用电脑
```
